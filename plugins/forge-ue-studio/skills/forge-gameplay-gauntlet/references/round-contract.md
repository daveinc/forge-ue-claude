# Gauntlet round contract

Record the baseline revision, target/reference, one bottleneck, rubric, variants, fixed capture conditions, play evidence, in-engine frames, critic identity, blind mapping, scores, winner, regressions, performance delta and human decision.

Visual tools support the game loop:

- use raster generation for concepts, sprites, textures, UI and boards;
- use Blender or Unreal for verified meshes, rigs and animation;
- compare integrated results in engine;
- do not replace playable iteration with endless image or DCC rounds.
