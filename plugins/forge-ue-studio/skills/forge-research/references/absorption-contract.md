# Absorption contract

Each integration must provide:

```text
capability
provider and exact version
status and proof timestamp
mode and resource lane
input/output schema or catalog hash
enabled workflow steps
constraints and declared write scope
fallbacks or blocking rule
known-good and seeded-bad probes
acceptance suites
invalidation triggers
licence, provenance, effective cost, and secret boundary
```

For documentation or project corpora, also record discovery scope, source authority, classification, extracted decisions/requirements/constraints, conflicts, approval status, retrieval keys and destination contracts. Never merge competing acceptance variants before the conflict owner resolves them.

For local models, also record model identity, quantization, context, modalities, tool behavior, VRAM/RAM use, throughput, task-specific quality, and verification cost. For MCPs, record transport, tool catalog, schemas, read/write classification, health, and failure isolation.

Treat Codex as the resident baseline. Qualify local extraction, code, review, visual breakdown, image work and Blender/Unreal operation independently by complexity tier. Record measured resident-context savings; do not infer savings from model locality alone.
